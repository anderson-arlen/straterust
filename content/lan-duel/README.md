# Original LAN combat check

A short original two-human map using the Terran demonstration's rules. One
rifle unit starts on each side; player 1's unit starts damaged. Fog keeps the
initial opponent hidden. The process integration check orders player 0 to
attack-move to (448, 240), completes the fight and checks every host replay hash.
Clients load rules only and download the host's public map.

This is a verification fixture rather than a balanced multiplayer map. It uses
the repository's MIT license and contains no proprietary artwork or sound.
